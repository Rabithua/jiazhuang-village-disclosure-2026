## 主要待核对事项

1. 电脑账面原值和净值均为3500元，核实原值和净值均为1592600元，差额1589100元进入固定资产汇总，应核对明细并重算总额。
2. 议题二所列资产1146.14万元，与补充说明1149.1567万元相差30167元，需要说明差额并统一最终版本。
3. 小学和广场仍在使用的状态，不能直接说明资产归属，应补充产权、移交及入账依据。
4. 新增14项资产及5个问题已整改的表述，需要对应的新增清单和逐项整改结果。
5. 发包方案中的特殊情况下签订超低价合同，需要明确适用条件、价格依据和监督程序。
6. 部分公示表格字号过小、照片模糊或倾斜，个别内容被截断，应提供完整清晰的电子表格或扫描件。

以上为初始六条反馈。后续逐项核查已整理为[20个问题及优先顺序](https://github.com/Rabithua/jiazhuang-village-disclosure-2026/issues/21)，具体证据和补充材料请求见各Issue；原始资料位置见[问题与来源索引](materials/04_整理文本/02_问题与来源索引.txt)。

## 文件完整性

原始PDF和截图已逐文件核对字节内容。仓库中的[SHA256SUMS.txt](materials/SHA256SUMS.txt)记录资料包内其他21个文件的SHA-256。

政策目录使用独立的[文件清单](policies/文件清单.json)和[SHA-256校验表](policies/SHA256SUMS.txt)，不改变原始公示资料的清单和校验值。在仓库根目录运行以下命令，可使用Python 3标准库验证两个目录的全部归档文件：

```bash
python3 scripts/verify_materials.py
```

发布页的原始公示资料包与最初整理的ZIP一致，SHA-256为：

```text
8b8fce8c929f246bdfb80245b3a0cfc4883521a9b0629b211dc192222b03c83b
```

校验值用于核对文件之后是否发生字节变化，不用于证明公示内容本身真实。
