## 使用范围与待补材料

- 本次会议为集体经济组织成员代表大会。省办法第10条规定其可依章程行使部分职权，但农村土地承包、宅基地使用、经营性资产收益权份额量化及土地补偿费分配使用等所列职权除外。须核本次方案事项性质、现行法律和章程授权，不能把成员代表大会和村民代表会议直接等同，也不能仅凭“一村一策”名称判断其职权是否适用。
- 省办法第18条关于分主体设账户（簿）的表述，适用于实行会计委托代理的地方。第26条的交易方式针对其所列集体所有、未采取家庭承包的“四荒”、果园、养殖水面等资源租赁；须结合具体地类判断。
- 工作部署报道提供整治方向，地方实践提供核查方法，均不代替具体文件条款。
- 本次公开检索未取得省级专项行动方案及“九查”完整正文、南阳市相关指导意见及“三张清单”、本村适用的签到照归档指引，以及11类底价和期限的完整制定依据，列为待向有关部门核实的材料。
- 所引条款未直接规定PDF像素标准。要求公示完整、清晰、可查阅，不能编造统一分辨率或“必须本人正面照”的省级规定。
